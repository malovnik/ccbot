# CCBot

Telegram-бот, связывающий топики Telegram-форума с сессиями Claude Code через tmux. Каждый топик привязан к одному tmux-окну с запущенным экземпляром Claude Code. Сообщения из Telegram пересылаются в Claude Code, ответы возвращаются обратно в реальном времени.

## Возможности

### Telegram-интеграция

- Ввод текста, фото, голосовых сообщений, документов
- Транскрипция голоса через Deepgram Nova-3
- Пересылка правок сообщений с пометкой "Исправление"
- Пересланные сообщения дополняются контекстом об авторе
- Цитата-ответ добавляет контекст цитируемого текста к запросу
- Реакции на сообщения бота транслируются как фидбек Claude (19 маппингов)
- Автоименование топиков по первому сообщению
- Пагинированная история сообщений
- Скриншот терминала в PNG с поддержкой ANSI-цветов и Unicode
- Автоотправка записанных файлов (.md, .txt, .pdf, .docx и др.)

### Мониторинг сессий

- Polling JSONL-файлов сессий по byte offset (инкрементальное чтение)
- Прогресс в реальном времени: какой инструмент использует Claude
- Автоперезапуск Claude при крашах (--resume, до 2 попыток, cooldown 60 секунд)
- Уведомление при бездействии (по умолчанию 120 секунд)
- Обнаружение мертвых сессий и автоочистка привязок
- Хук SessionStart для автоматического отслеживания новых сессий
- Группировка быстрых сообщений (debounce 1.5 секунды)
- Длинные ответы: превью в чате + полный текст как .md-файл

### WebSocket Bridge

- WS-сервер для веб-фронтенда (26 типизированных dataclass-сообщений)
- Аутентификация через HMAC-сравнение токенов
- Периодический diff-capture терминала
- Standalone-режим (`ccbot web`) или совместный (`--with-web`)
- Rate limiting: 60 сообщений в минуту на соединение
- Максимум 20 одновременных соединений

### Безопасность

- Whitelist пользователей по Telegram ID
- Ограничение директорий через `CCBOT_ALLOWED_ROOTS`
- Скрабинг чувствительных переменных из `os.environ` и tmux-среды после загрузки
- Rate limiting: 30 сообщений / 60 секунд на пользователя + глобальный 30/с Telegram API
- Фильтрация вывода инструментов (предотвращение утечки Bash-результатов и секретов)
- Блокировка отправки sensitive-файлов (.env, credentials, id_rsa и др.)
- Валидация UUID session_id, `shlex.quote()` для команд tmux
- Логи с правами `chmod 600`

## Быстрый старт

**1. Клонировать и установить**

```bash
git clone https://github.com/malovnik/ccbot.git
cd ccbot
uv sync
```

**2. Настроить переменные окружения**

```bash
mkdir -p ~/.ccbot
cp .env.example ~/.ccbot/.env
```

Отредактировать `~/.ccbot/.env`:
- `TELEGRAM_BOT_TOKEN` -- получить у [@BotFather](https://t.me/BotFather)
- `ALLOWED_USERS` -- узнать свой ID у [@userinfobot](https://t.me/userinfobot)

**3. Установить хук Claude Code**

```bash
uv run ccbot hook --install
```

**4. Запустить**

```bash
uv run ccbot
```

Бот работает в режиме Forum (Topics). Группа в Telegram должна иметь включенные топики. Каждый новый топик при первом сообщении предложит выбрать директорию проекта для создания сессии Claude Code.

## Команды бота

### Управление сессией

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие и краткая справка |
| `/help` | Полный список команд и возможностей |
| `/screenshot` | Скриншот терминала tmux в PNG с клавиатурой управления |
| `/history` | Пагинированная история сообщений сессии |
| `/summary` | Структурированный обзор сессии: файлы, команды, действия |
| `/esc` | Отправить Escape в tmux (прервать Claude) |
| `/restart` | Перезапустить сессию в той же директории |
| `/kill` | Завершить сессию и удалить топик |
| `/unbind` | Отвязать топик от tmux-окна без завершения сессии |

### Мониторинг

| Команда | Описание |
|---------|----------|
| `/health` | Диагностика: uptime, количество сессий, состояние tmux, память |
| `/sessions` | Список всех активных сессий с индикатором работы Claude |
| `/usage` | Расход токенов текущей сессии Claude Code |

### Проксируемые команды Claude Code

Следующие команды пересылаются напрямую в Claude Code через tmux:

`/clear` `/compact` `/cost` `/model` `/memory`

Любая другая `/команда` также пересылается в Claude Code как есть.

## Конфигурация

Файл `.env` загружается из `~/.ccbot/.env` (или `$CCBOT_DIR/.env`). Локальный `.env` в текущей рабочей директории имеет приоритет.

### Обязательные переменные

| Переменная | Описание |
|------------|----------|
| `TELEGRAM_BOT_TOKEN` | Токен бота от @BotFather |
| `ALLOWED_USERS` | Telegram user ID через запятую |

### tmux

| Переменная | По умолчанию | Описание |
|------------|-------------|----------|
| `TMUX_SESSION_NAME` | `ccbot` | Имя tmux-сессии |
| `CLAUDE_COMMAND` | `claude` | Команда запуска Claude Code в новых окнах |

### Polling

| Переменная | По умолчанию | Описание |
|------------|-------------|----------|
| `MONITOR_POLL_INTERVAL` | `2.0` | Интервал опроса JSONL-файлов в секундах (минимум 0.5) |

### Голосовые сообщения

| Переменная | По умолчанию | Описание |
|------------|-------------|----------|
| `DEEPGRAM_API_KEY` | -- | API-ключ Deepgram для транскрипции голоса |

### Безопасность

| Переменная | По умолчанию | Описание |
|------------|-------------|----------|
| `CCBOT_ALLOWED_ROOTS` | `~` | Разрешенные корневые директории через запятую |

### Поведение

| Переменная | По умолчанию | Описание |
|------------|-------------|----------|
| `CCBOT_IDLE_REMINDER_SECONDS` | `120` | Таймаут напоминания о бездействии (0 = отключено) |
| `CCBOT_AUTO_RESTART` | `true` | Автоперезапуск Claude при крашах |
| `CCBOT_FILE_RETENTION_DAYS` | `7` | Хранение скачанных файлов в днях (0 = отключено) |
| `CCBOT_LONG_RESPONSE_THRESHOLD` | `6000` | Порог символов для превью + .md файл |
| `CCBOT_INPUT_BATCH_SECONDS` | `1.5` | Группировка быстрых сообщений (debounce) |

### Вывод

| Переменная | По умолчанию | Описание |
|------------|-------------|----------|
| `CCBOT_CLEAN_OUTPUT` | `true` | Фильтровать вывод инструментов, показывать только ответы Claude |
| `CCBOT_SHOW_USER_MESSAGES` | `false` | Эхо пользовательских сообщений с префиксом |
| `CCBOT_SHOW_HIDDEN_DIRS` | `false` | Показывать dot-директории в браузере |

### WebSocket Bridge

| Переменная | По умолчанию | Описание |
|------------|-------------|----------|
| `CCBOT_WS_ENABLED` | `false` | Включить WS-сервер для веб-фронтенда |
| `CCBOT_WS_HOST` | `127.0.0.1` | Адрес привязки WS-сервера |
| `CCBOT_WS_PORT` | `8765` | Порт WS-сервера |
| `CCBOT_WS_TOKEN` | -- | Токен аутентификации WS-соединений (обязателен при включенном WS) |

### Системные

| Переменная | По умолчанию | Описание |
|------------|-------------|----------|
| `CCBOT_DIR` | `~/.ccbot` | Директория конфигурации и состояния |
